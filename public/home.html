Chapter III

Build

KiwotHire, built end to end

Then I built one from the ground up.

Applicant tracking for recruiters across Europe. Next.js, TypeScript, Supabase and Stripe, running on Vercel and Hetzner.

Every CV gets scanned and fingerprinted.

ClamAV checks each upload. A SHA-256 hash means a file that’s already been processed is never processed again.

Billing that never charges twice.

Stripe webhooks are idempotent, so a retried event applies once. I traced 82 failed deliveries to one misconfigured endpoint and fixed it.
